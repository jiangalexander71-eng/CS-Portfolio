#ChadaTechClocks
This program is a console based dual-clock application that is written in C++. It prompts the user for an initial time, validates the time within a standard 24 hour clock, then displays the time in both 12 and 24-hour format. Then there is a menu that allows the user to adjust the time, until the user decides to exit. 

One thing I felt I did well is maximize the use of functions while minimizing the repeating code. I have tended to have a lot of duplicate code in my previous programs that worked but were complicated to write and weren't efficient at all. By purposefully using functions, my code is a lot cleaner, readable, and easier to adapt in the future. 

Something I could do to enhance my code would be to add more input validation such as catch cases for letters or strings when expecting a number. This prevents the program from acting erratically due to unexpected cases. 

For me, the most difficult part about building this application would be handling the time rollover. I had a difficult time with the 12-hour function and getting it to output the right time when it would change from am to pm, so I ended up writing a bit of pseudocode and planning to help alleviate some of the trouble. 

Some skills that are transferable to other projects or coursework is utilizing functions, validating user input, and planning the program out instead of jumping straight into programming. All of these skills can be applied to larger programs with more complex code due to these skills acting as a foundation. 

I made the program maintainable by using industry standard naming schemes to make it easy for a peer to read. I used comments throughout the code to explain each section or function, allowing the code to be easily readable. I also utilized functions effectively throughout the program, making the program more adaptable by changing only the function instead of multiple components of the code when a change is needed.
